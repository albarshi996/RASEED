## المبدأ الحاكم

> **كل عملية تُسجَّل مرة واحدة، ثم ينعكس أثرها تلقائيًا على جميع الشاشات والتقارير والأرصدة
> المرتبطة بها، دون تكرار البيانات أو تضارب الحسابات.**

النظام يقوم على **قيد مزدوج صارم**: كل حركة تولّد قيدًا متوازنًا، والتقرير دالّة في
**نوع الحساب** لا في حقل وصفي. ولهذا لا يمكن بنيويًا أن يتسرّب تحويل بين حسابين إلى
تقرير الدخل، ولا أن يُحتسب قرض استلمته دخلًا.

## البدء

1. افتح **https://raseed-2fac1.web.app**
2. سجّل الدخول بحساب Google.
3. أدخل رصيدك الافتتاحي (كم معك الآن فعلًا).
4. ابدأ بتسجيل المصاريف.

## التطوير

```bash
npm install
npm run dev            # خادم التطوير
npm run verify         # typecheck + lint + 165 اختبار وحدة
npm run test:rules     # 52 اختبارًا على محاكي Firestore (يتطلب Java 21)
npm run deploy:rules   # نشر القواعد والفهارس
npm run build          # بناء الإنتاج
```

## ما يعمل الآن

- ✅ تسجيل الدخول بحساب Google (النظام مغلق على المالك في قواعد الأمان)
- ✅ شجرة حسابات كاملة تُنشأ تلقائيًا عند أول دخول
- ✅ الرصيد الافتتاحي كقيد متوازن
- ✅ تسجيل المصاريف بالفئة والحساب والتاريخ والنوع (شخصي/منزلي)
- ✅ أرصدة حيّة وآخر العمليات
- ✅ PWA قابل للتثبيت على الهاتف
