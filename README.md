# رَصيد | RASEED

**منظومة الإدارة المالية والشخصية المتكاملة** — كل مصاريفك تحت السيطرة.

> تطبيق ويب عربي (RTL) لإدارة المال والالتزامات والديون والمهام والعبادات من مكان واحد.
> مبني على React + TypeScript + Firebase، بعملة افتراضية **الدينار الليبي (LYD)**.

| | |
|---|---|
| **مالك المشروع** | محمد إبراهيم البرشي |
| **مشروع Firebase** | `raseed-2fac1` |
| **اللغة / الاتجاه** | العربية / RTL حقيقي |
| **العملة** | الدينار الليبي (LYD) |
| **الحالة** | 🚧 قيد التأسيس — مرحلة التصميم المعماري |

## المبدأ الحاكم

> **كل عملية تُسجَّل مرة واحدة، ثم ينعكس أثرها تلقائيًا على جميع الشاشات والتقارير والأرصدة
